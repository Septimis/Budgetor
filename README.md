# Budgetor

Budgetor is a personal & family finance tool intended to help they layman get ahold of their finances. Budgetor uses the intuitive concept of water flowing from one container to another to simulate the flow of money as it comes in to their possession and leaves.

## Build & Run Instructions

Currently Budgetor is only available on Web, but there are plans to push its availability to iOS, Android, and desktop applications.

> ### Pre-requisites
>
> - [ ] DotNet 9.0 or later

1. Navigate to ~/src
2. Run `dotnet watch`
3. Navigate to `localhost:4848` in your web browser
